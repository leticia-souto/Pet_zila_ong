# 🐾 Pet Zila

Site de adoção de pets desenvolvido como projeto avaliativo (Formativa 1).

## 📋 Sobre o projeto

O **Pet Zila** é uma página web que apresenta cães disponíveis para adoção, exibindo informações como nome, sexo, espécie, porte, raça e idade de cada animal, em um layout de cards responsivo.

## 🛠️ Tecnologias utilizadas

- **HTML5**
- **Tailwind CSS**
- **CSS** (estilizações customizadas)
- **JavaScript**
